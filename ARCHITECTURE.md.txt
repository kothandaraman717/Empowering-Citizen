## Core Modules

### 1. Voice Interaction Engine
- Speech recognition captures user audio via browser APIs.
- Audio transcriptions map directly to form field state variables.
- TTS engine reads back question prompts and eligibility outcomes in selected regional languages.

### 2. Scheme Rule Matching Logic
Schemes are stored as JSON predicates:
```json
{
  "id": "pm_kisan",
  "name": "PM-Kisan Samman Nidhi",
  "minAge": 18,
  "maxAge": 100,
  "category": "farmer",
  "maxIncome": 250000
}
