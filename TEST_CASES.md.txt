# Test Cases & Sample Data

## Sample Input Data Scenarios

### Test Case 1: Low-Income Farmer (Central Scheme Focus)
* **Age:** 35
* **Gender:** Male
* **Occupation:** Farmer
* **Annual Income:** ₹1,50,000 (Low / BPL)
* **State:** Uttar Pradesh
* **Expected Eligible Schemes:**
  1. PM-Kisan Samman Nidhi (Income <= ₹2,50,000, Farmer)
  2. Ayushman Bharat (Income <= ₹2,50,000)
  3. PM Vishwakarma Yojana (If category craft skills apply)

## Quick API Test Script (Browser Console)

Run this snippet in the browser console on `index.html` to test rule engine matching programmatically:

```javascript
const sampleUser = { age: 32, gender: 'female', category: 'farmer', income: 150000, state: 'MP' };
const matches = schemes.filter(s => 
  sampleUser.age >= s.minAge && 
  sampleUser.age <= s.maxAge && 
  (s.category === 'all' || s.category === sampleUser.category) &&
  sampleUser.income <= s.maxIncome
);
console.log("Eligible Schemes Count:", matches.length);
console.table(matches);
